这是一份面向巴西市场的多平台内容分发管理系统，模拟了从一个后台统一管理 Instagram、TikTok、Facebook、YouTube、LinkedIn、Twitter/X、Pinterest、WhatsApp 共 8 个社交媒体平台的全部流程——从内容创作、多平台预览、合规审核、一键分发到数据分析和定时排期。

💡 设计语言：采用深蓝（#1a3a5c）+ 金棕（#bfa46f）的高端商务配色，侧边栏使用深色渐变，主区域使用浅色卡片布局，整体呈现专业 SaaS 后台的视觉风格。界面语言以葡萄牙语为主、中文标注为辅。

5. 6 大功能页面

📊 1. 仪表盘 (Dashboard)

欢迎栏 + 4 个快捷操作卡 + 4 个统计卡片（收入/转化/触达/CPM）+ 柱状图 + 平台分布 + 活动时间线。展示运营全局概览。

🚀 2. 发布页 (Publish) — 核心

三列布局：左列编辑器（标题输入、内容文本域、格式工具栏、媒体上传、快捷标签）+ 中列预览（8 平台 Tab 切换预览）+ 右列平台选择（8 个平台卡片、一键分发按钮、内容素材库）。

支持 8 个平台的实时预览，每个平台有独立的预览样式。底部嵌入内容素材库（3 个分类标签页：多平台分发、巴西汽车出海、短句素材）。

✅ 3. 合规审核 (Revisão)

4 步审核流程可视化（上传内容 → AI 检测 → 人工确认 → 完成发布），支持图片/视频上传预览、外部链接添加、合规检测项勾选。

👥 4. 账号管理 (Accounts)

8 个平台账号卡片网格，展示平台名、Handle、粉丝数、发布数、状态（已连接/未连接）。

📈 5. 数据分析 (Data)

4 个统计卡片 + 平台数据表格（粉丝/互动率/转化率/收入）+ 数据概览面板。

📅 6. 定时排期 (Schedule)

月历视图 + 待发布列表，支持日历单元格点击、发布时间设置、重复频率选择。数据通过 localStorage 持久化。

五彩纸屑实现

function pubLaunchConfetti() {
  var container = document.createElement('div');
  container.className = 'pub-confetti-container';
  document.body.appendChild(container);

  var colors = ['#bfa46f','#1a3a5c','#2d9d78','#d4943a',
                '#7c5bba','#d4504e','#0a8db3','#E1306C',
                '#1877F2','#25D366'];
  var pieces = 80;

  for (var i = 0; i < pieces; i++) {
    var piece = document.createElement('div');
    piece.className = 'pub-confetti-piece';
    // 随机位置、颜色、大小、形状、时长、延迟
    piece.style.left = Math.random()*100 + '%';
    piece.style.background = colors[Math.floor(Math.random()*colors.length)];
    piece.style.width = (6+Math.random()*8) + 'px';
    piece.style.height = (6+Math.random()*8) + 'px';
    piece.style.borderRadius = Math.random()>0.5 ? '50%' : '2px';
    piece.style.animationDuration = (1.8+Math.random()*2.5) + 's';
    piece.style.animationDelay = (Math.random()*0.6) + 's';
    container.appendChild(piece);
  }

  // 5 秒后自动清理
  setTimeout(function() {
    if (container.parentNode) container.remove();
  }, 5000);
}

9. 定时发布与日历

日历组件

月历视图，每个日期单元格支持三种状态：today（今天，高亮）、has-posts（有排期，金棕边框）、普通日期。点击日期可添加排期。

数据持久化

var schScheduledPosts = []; // 排期数组
var SCH_KEY = 'sch_posts';   // localStorage 键名

function schSavePosts() {
  localStorage.setItem(SCH_KEY, JSON.stringify(schScheduledPosts));
}

function schLoadPosts() {
  try {
    var raw = localStorage.getItem(SCH_KEY);
    if (raw) schScheduledPosts = JSON.parse(raw) || [];
  } catch(e) { schScheduledPosts = []; }
}

首次打开时如果没有排期数据，会自动生成 6 条演示数据（Instagram/TikTok/LinkedIn/Facebook/Twitter/YouTube 各一条），覆盖今天、明天和后天。
