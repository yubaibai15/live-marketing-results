这是什么？

skills-with-timeline.html 是一个单文件 HTML 应用，仿写了扣子（Coze）AI 智能体平台的规则配置页面。它模拟了一个名为"社媒智能营销Agent"的 AI 智能体编辑界面，包含规则配置、知识库管理、技能矩阵、工作流管理四大功能模块，以及一个右侧效果预览聊天面板。

2. 技术栈

HTML 结构层

  • 标准 HTML5 文档结构（DOCTYPE + meta viewport + charset）
  • 语义化标签：<nav> 导航、<button> 交互元素
  • 内联 SVG 图标：全部使用 viewBox="0 0 24 24" 的 stroke 风格 SVG，无外部图标库依赖
  • data-* 属性驱动：data-page、data-kb、data-id、data-value 等

CSS 样式层

  • CSS 变量系统：在 :root 中定义 30+ 个设计 token（颜色/圆角/阴影/间距）
  • Flexbox 布局：全站采用 flex 弹性布局，无 float/grid（除技能卡片用 grid）
  • CSS Grid：仅用于技能矩阵的响应式卡片网格
  • 过渡动画：transition 全局 0.15s，统一交互节奏
  • 关键帧动画：@keyframes 实现聊天入场、打字气泡、文件淡入
  • iOS 风格开关：纯 CSS 实现的 toggle switch
  • 响应式：@media 断点 900px/520px 适配
  • 滑块自定义：-webkit-slider-thumb + 渐变背景填充

JavaScript 逻辑层

  • 纯原生 JS：无任何框架（Vue/React/jQuery 均未使用）
  • DOM 操作：getElementById / querySelector / addEventListener
  • localStorage：规则页配置持久化（模型设置、字段权重等）
  • IIFE 模块化：技能矩阵和规则页各自用 (function(){...})() 封装
  • ResizeObserver：监听预览面板可见性变化，重算 textarea 高度
  • File API：知识库文件上传，持有 File 引用
  • Clipboard API：脚本复制功能
  • Fullscreen API：营销日历全屏预览
  • Beacon SDK：腾讯灯塔埋点上报（页面访问统计）

外部依赖

  • 唯一外部 JS：https://beacon.cdn.qq.com/sdk/4.5.9/beacon_web.min.js（腾讯灯塔 SDK）
  • 无 CSS 外部依赖、无字体 CDN、无图片资源（全部内联 SVG）
  • iframe 外链：calendar-poster.html（全年营销日历全屏预览页）

3.3 页面切换机制

所有页面（.page）默认 display:none，只有带 .active 类的才显示为 display:flex。点击左侧导航时，JS 移除所有 .nav-item 和 .page 的 .active，然后给被点击项和对应页面加上 .active。

// 导航切换核心逻辑（第 2116-2131 行）
document.querySelectorAll('.nav-item').forEach(item => {
  item.addEventListener('click', () => {
    // 移除所有 active
    document.querySelectorAll('.nav-item').forEach(n => n.classList.remove('active'));
    document.querySelectorAll('.page').forEach(p => p.classList.remove('active'));
    // 激活当前项
    item.classList.add('active');
    const page = document.getElementById('page-' + item.dataset.page);
    if (page) page.classList.add('active');
    // 仅"技能矩阵"页面显示右侧预览面板
    if (item.dataset.page === 'skill') {
      previewPanel.classList.add('visible');
    } else {
      previewPanel.classList.remove('visible');
    }
  });
});

4. Codex 增量构建策略

这个网页不是一次性写成的，而是通过14 轮 Codex 对话（1 轮初始化 + 13 轮追加）逐步构建的。每一轮发送一段提示词 + 代码片段，Codex 在同一文件上追加内容。

4.1 为什么要增量构建？

  • HTML 文件达 3533 行 / 144KB，单次发送会超出 AI 的上下文/输出长度限制
  • 分步发送可以让 AI 聚焦于每一小段，质量更高
  • 每一步有明确的板块划分，出错时只需重发某一步
  • 13 步的设计让代码有清晰的"建造轨迹"，便于后续维护

7.3 聊天对话系统

消息追加函数

function appendMessage(role, text) {
  const welcome = chatBody.querySelector('.chat-welcome');
  if (welcome) welcome.remove();           // 移除欢迎语
  const wrap = document.createElement('div');
  wrap.className = 'chat-msg ' + role;     // user / ai
  // 创建头像 + 气泡
  const avatar = document.createElement('div');
  avatar.className = 'chat-avatar ' + (role === 'user' ? 'user-avatar' : 'ai');
  const bubble = document.createElement('div');
  bubble.className = 'chat-bubble';
  bubble.textContent = text;
  wrap.appendChild(avatar);
  wrap.appendChild(bubble);
  chatBody.appendChild(wrap);
  chatBody.scrollTop = chatBody.scrollHeight; // 自动滚动到底
}

打字动画（模拟 AI 思考）

function showTyping() {
  // 创建三个跳动圆点
  bubble.className = 'chat-bubble typing';
  bubble.innerHTML = '<span></span><span></span><span></span>';
}
function hideTyping() {
  document.getElementById('typing-indicator')?.remove();
}
// 延迟后显示回复
function aiSay(text, delay) {
  return new Promise(resolve => {
    showTyping();
    setTimeout(() => {
      hideTyping();
      appendMessage('ai', text);
      resolve();
    }, delay || 800);
  });
}

function guessKbByName(fileName) {
  const lower = fileName.toLowerCase();
  for (const r of KB_NAME_RULES) {

}

function bindNumberBox(inputId, min, max, step, key) {
  const input = document.getElementById(inputId);
  const wrap = input.closest('.ms-number-box');
  const minus = wrap.querySelector('.ms-num-minus');
  const plus = wrap.querySelector('.ms-num-plus');
  function update(val) {
    val = Math.max(min, Math.min(max, Math.round(val / step) * step));
    input.value = val;
    modelSettings[key] = val;
  }
  minus.addEventListener('click', () => update(parseFloat(input.value) - step));
  plus.addEventListener('click', () => update(parseFloat(input.value) + step));
}

8. 核心功能点逐个拆解

8.1 模型选择器下拉菜单

点击模型名称按钮 → 下拉菜单 classList.toggle('show') → 选择模型 → 更新 modelSettings.model → syncModelSettingsUI() 同步 UI。点击外部关闭通过 document.addEventListener('click') 检测 e.target.closest('.model-selector-wrap') 实现。

8.2 生成多样性模式切换

4 个模式按钮（精确/平衡/创意/自定义），互斥选中。选择"自定义"时才显示"重复语句惩罚"滑块行。滑块和数字框双向绑定，滑块背景使用 linear-gradient 动态填充已选区域。

8.3 角色字段动态渲染

角色设定区域的字段（角色/回复逻辑）完全由 JS 动态生成。每个字段包含：可编辑名称输入框、Tab 标签、权重显示、设置按钮（弹出菜单：重命名/增减权重）、自适应高度的 textarea。字段值通过 input 事件实时写入 fields 数组。

8.4 知识库加号按钮 + 隐藏 input

每个知识库卡片有一个加号按钮，点击后创建一个隐藏的 <input type="file" multiple> 并触发 .click()。选择文件后自动添加到对应知识库的文件列表，卡片边框闪烁绿色高亮反馈。文件列表支持逐个删除。

8.5 知识库批量上传 + 智能匹配

主上传窗口支持点击打开批量弹窗或直接拖拽文件入库。批量弹窗中选中的文件根据文件名关键词自动匹配到 6 个知识库（如文件名含"巴西民俗"→ culture 库），未匹配的文件默认入"巴西民俗文化库"。

8.6 技能矩阵搜索 + 筛选

搜索框实时过滤技能（按标题和描述匹配），标签栏提供"全部"和"已选"两个筛选维度。卡片点击切换选中状态，选中后卡片边框变绿、显示勾选标记。"全选"按钮根据当前状态显示"全选"或"取消全选"。

8.7 聊天对话模拟

输入框支持 Enter 发送 / Shift+Enter 换行。发送后：①显示用户消息 → ②AI 打字动画（随机延迟 600-1400ms）→ ③AI 回复"正在调用..." → ④再次打字（2000ms）→ ⑤显示营销日历结果卡片。日历卡片点击后触发 Fullscreen API 全屏预览 iframe。

8.8 直播脚本卡片

buildFullScript() 函数返回一个完整的直播脚本 HTML 字符串（约 90 行），包含 7 个部分（暖场/海鸥/宋PLUS/汉EV/互动/逼单/收官）+ 合规自查清单。脚本卡片有渐变标题栏、可滚动内容区、复制/导出按钮。复制功能使用 navigator.clipboard.writeText。

8.9 textarea 自适应高度

两个独立的自适应函数：① autoResize(el) 用于规则页字段（直接设为 scrollHeight）；② autoResizeTextarea(el) 用于聊天输入框（限制 22-120px）。聊天输入框还通过 ResizeObserver 监听面板可见性变化，面板从隐藏变为可见时重新计算高度。

8.10 Beacon 埋点上报

页面加载时初始化腾讯灯塔 SDK，上报 preview_page_view 事件，包含 URL、referrer、title 和 sandbox_id。使用 try-catch 包裹，失败不影响页面功能。
